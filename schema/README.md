# Vendored OpenBook schema

This directory is a pinned copy of `schema/` from
[openbook-data-standards/openbook](https://github.com/openbook-data-standards/openbook).
Do not edit it by hand; run `node scripts/sync-schema.mjs` to refresh it and
`node scripts/sync-schema.mjs --check` to detect drift.

The version these files were copied from is in `../openbook-spec-version`.
